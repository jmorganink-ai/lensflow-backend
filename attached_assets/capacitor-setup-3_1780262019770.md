# TelePrompt Pro — Native Packaging with Capacitor

This guide converts your React web app into a native iOS and Android app using Capacitor.
Estimated setup time: ~30 minutes. No Expo, no React Native — just your existing React code.

---

## Project Structure

```
teleprompt-pro/
├── src/
│   ├── main.jsx          ← React entry point
│   └── App.jsx           ← Your teleprompt.jsx (rename and paste here)
├── public/
│   └── index.html
├── ios/                  ← Generated by Capacitor
├── android/              ← Generated by Capacitor
├── dist/                 ← Vite build output (what Capacitor serves)
├── package.json
├── vite.config.js
└── capacitor.config.ts
```

## 2. capacitor.config.ts

```typescript
import { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId:   'com.yourname.telepromptpro',   // ← change to your bundle ID
  appName: 'TelePrompt Pro',
  webDir:  'dist',
  server: {
    androidScheme: 'https',                 // required for camera API on Android
  },
  ios: {
    contentInset: 'always',
  },
};

export default config;
```

## 6. iOS Permissions — Info.plist

After running `npm run ios` for the first time, open `ios/App/App/Info.plist` and add:

```xml
<!-- Inside the top-level <dict> -->

<key>NSCameraUsageDescription</key>
<string>TelePrompt needs your camera to record videos.</string>

<key>NSMicrophoneUsageDescription</key>
<string>TelePrompt needs your microphone to record audio and sync your voice with the script.</string>

<key>NSSpeechRecognitionUsageDescription</key>
<string>TelePrompt uses speech recognition to scroll the script as you speak.</string>
```

## 7. Android Permissions — AndroidManifest.xml

Open `android/app/src/main/AndroidManifest.xml` and add inside `<manifest>`:

```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28" />
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />

<!-- Required for front camera -->
<uses-feature android:name="android.hardware.camera.front" android:required="false" />
```

## 8. First-time Setup Commands

```bash
# 1. Install dependencies
npm install

# 2. Build the web app
npm run build

# 3. Add iOS and Android platforms (one-time)
npx cap add ios
npx cap add android

# 4. Sync web assets to native projects
npx cap sync

# 5. Open in Xcode (iOS)
npx cap open ios

# 6. Open in Android Studio (Android)
npx cap open android
```

## 9. Ongoing Development Workflow

```bash
# After any code change:
npm run build && npx cap sync

# Then rebuild from Xcode / Android Studio,
# OR use live reload for faster iteration:
npx cap run ios    --livereload --external
npx cap run android --livereload --external
```

## 10. Recording Format — iOS Compatibility Fix

Safari on iOS doesn't support `video/webm`. Add this to your `App.jsx` MediaRecorder setup:

```javascript
// Replace the MediaRecorder line with:
const mimeType = MediaRecorder.isTypeSupported('video/mp4')
  ? 'video/mp4'
  : MediaRecorder.isTypeSupported('video/webm;codecs=vp9,opus')
  ? 'video/webm;codecs=vp9,opus'
  : 'video/webm';

const mr = new MediaRecorder(streamRef.current, { mimeType });

// And update the download blob:
const blob = new Blob(chunks.current, { type: mimeType });
const ext  = mimeType.includes('mp4') ? 'mp4' : 'webm';
// download as take-TIMESTAMP.mp4 or .webm
```

## 11. App Store & Play Store Checklist

**iOS (App Store Connect)**
- [ ] Set bundle ID in `capacitor.config.ts` → matches App Store Connect
- [ ] Add app icons: 1024×1024 PNG in `ios/App/App/Assets.xcassets/AppIcon.appiconset/`
- [ ] Set launch screen in Xcode → `LaunchScreen.storyboard`
- [ ] Enable "Background Modes → Audio" capability in Xcode if needed
- [ ] Set minimum deployment target to iOS 15+

**Android (Google Play Console)**
- [ ] Set `applicationId` in `android/app/build.gradle`
- [ ] Add app icons in `android/app/src/main/res/mipmap-*/`
- [ ] Set `minSdkVersion 24` and `targetSdkVersion 34` in `build.gradle`
- [ ] Generate signed APK/AAB via Android Studio → Build → Generate Signed Bundle

## 12. Voice Sync — Platform Notes

| Platform | Engine | Notes |
|---|---|---|
| iOS Safari | Apple Speech Framework | Works well; requires `NSSpeechRecognitionUsageDescription` |
| Android Chrome | Google Speech Services | Excellent accuracy; no extra setup |
| Firefox (any) | ❌ Not supported | Falls back to Auto Speed mode gracefully |

For offline/server-side transcription accuracy, you can later swap the `SpeechRecognition` calls for a chunked **OpenAI Whisper API** pipeline — useful for post-production captioning but adds ~1–2s latency for real-time scrolling.
