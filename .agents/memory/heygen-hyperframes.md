# HeyGen HyperFrames

**Endpoint:** Not yet documented in detail — see `/hyperframes` in HeyGen docs.

Renders HTML/CSS/JS compositions into motion-graphics video. Labeled "New" in the v3 quick-start guide.

## Use cases for LensFlow
- Animated property stats / data overlays (price, beds, baths, suburb)
- Branded intro/outro cards rendered from HTML templates
- Lower-third name tags and call-to-action frames
- Listing summary cards that animate in programmatically

## Key facts
- Part of the v3 API surface
- No avatar or script required — pure HTML/CSS/JS to video
- Could complement presenter videos: generate presenter clip + HyperFrame overlay, composite via Shotstack

## v1/v2 sunset
Both supported until **October 31, 2026**. All new capabilities on v3 only.
