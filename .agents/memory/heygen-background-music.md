# HeyGen Background Music

## Search
```
GET /v3/audio/sounds?query=upbeat+corporate+background&limit=3
```
Returns ranked tracks with pre-signed WAV download URLs.

### Parameters
| Param | Default | Description |
|-------|---------|-------------|
| `query` | required | Natural-language description — semantic search, not keyword |
| `limit` | 10 | 1–50 results |
| `min_score` | 0.7 | Similarity threshold (0–1); raise for tighter matches |
| `type` | `music` | Only `music` supported today; `sound_effect` reserved |
| `token` | — | Pagination cursor from previous `next_token` |

### Response item fields
| Field | Description |
|-------|-------------|
| `id` | Stable track ID |
| `name` | Display name |
| `description` | Mood/instrumentation description |
| `audio_url` | Pre-signed WAV URL — **short-lived, use immediately** |
| `duration` | Seconds |
| `score` | Similarity score (0–1) |

### ⚠️ Pre-signed URL lifetime
`audio_url` expires shortly after search. Download or pass to downstream step immediately — do NOT cache the URL.

## Pagination
When `has_more: true`, pass `next_token` as `token` on the next request.

## LensFlow use cases
- Add background music to the final Shotstack composite (mix at ~15–20% volume under voiceover)
- Semantic search from property mood: "luxury waterfront ambient", "modern urban corporate", "warm family home piano"
- Search query could be generated by Claude based on listing type + suburb

## Example queries for real estate
- Luxury / prestige: `"elegant orchestral background luxury real estate"`
- Family homes: `"warm uplifting acoustic family home"`  
- Commercial / investment: `"confident corporate professional"`
- Coastal / lifestyle: `"relaxed ambient beach lifestyle"`
